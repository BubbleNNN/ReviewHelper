设计一个结构，支持不断加入数字并随时查询当前所有数字的中位数：

```python
mf = MedianFinder()
mf.add(1); mf.add(2)
mf.median()   # 1.5
mf.add(3)
mf.median()   # 2.0
len(mf)       # 3
```

- `add(num)`：$O(\log n)$。
- `median() -> float`：$O(1)$。个数为偶数时返回中间两个数的平均值。没有任何数字时抛出 `ValueError`。
- `__len__`：当前数字个数。

场景：推理网关要在线显示 P50 首 token 延迟（TTFT）。请求源源不断进来，不能每次都排序。

### 讲解

**两个堆**：

- `lo`：大顶堆，存较小的一半（Python 只有小顶堆，存相反数）；
- `hi`：小顶堆，存较大的一半；
- 不变量：`lo` 的所有元素 ≤ `hi` 的所有元素，且 `len(lo) == len(hi)` 或 `len(lo) == len(hi) + 1`。

`add(x)`：先推进 `lo`，再把 `lo` 的最大值挪到 `hi`（保证有序不变量），如果 `hi` 比 `lo` 多了，就把 `hi` 的最小值挪回 `lo`（保证大小不变量）。每次 add 固定做 3 次堆操作，$O(\log n)$。

`median()`：奇数个取 `lo` 堆顶，偶数个取两个堆顶的平均。

**易错点**：

- 存相反数时，取出来要再取反。
- 只维护大小平衡、忘了“先过一遍另一个堆”，会破坏有序性。
- 偶数个时返回 float，`(a + b) / 2` 在 Python 3 里本来就是 float。

> [!Q]
> **线上要的是 P99 而不是 P50，而且数据量巨大怎么办？** 两堆法只适合精确中位数且内存装得下全部数据。线上一般用近似分位数：固定分桶的直方图（Prometheus histogram，分桶边界决定误差）、t-digest、DDSketch（相对误差有保证），都可以合并多个实例的统计。

> [!Q]
> **如果还要支持删除（滑动窗口中位数）？** 两个堆 + 延迟删除（用哈希表记录待删元素，堆顶是待删元素时再真正弹出），或者用平衡树 / `SortedList`，增删都是 $O(\log n)$。
