给定数组 `nums` 和窗口大小 `k`（`1 <= k <= len(nums)`），窗口从左滑到右，返回每个窗口内的最大值。要求 **O(n)**。

```python
max_sliding_window(nums, k) -> list
max_sliding_window([1, 3, -1, -3, 5, 3, 6, 7], 3)   # [3, 3, 5, 5, 6, 7]
```

返回列表长度为 `len(nums) - k + 1`。

场景：监控面板上要画“最近 k 秒的峰值显存 / 峰值排队长度”。每来一个采样点就要更新一次窗口最大值，不能每次都扫一遍窗口。

<!-- solution -->

### 讲解

**单调队列**：双端队列里存**下标**，保证对应的值从队头到队尾**严格递减**（或非增）。

每处理一个新下标 `i`：

1. 队尾所有 `nums[j] <= nums[i]` 的下标弹掉：它们比新来的小，又比新来的先过期，以后永远不可能当最大值；
2. `i` 入队尾；
3. 队头下标如果已经滑出窗口（`dq[0] <= i - k`）就弹掉；
4. `i >= k - 1` 时，队头就是当前窗口最大值。

**复杂度**：每个下标最多入队、出队各一次，均摊 $O(1)$，总 $O(n)$；空间 $O(k)$。

**易错点**：

- 队列里存值而不存下标，就判断不了队头有没有过期。
- 第 1 步用 `<` 还是 `<=` 都对；用 `<=` 队列更短。
- 用堆也能做（懒删除过期元素），复杂度 $O(n\log n)$，是可以接受的第二答案。

> [!Q]
> **如果窗口按时间而不是按个数（最近 10 秒内的采样，时间戳不均匀）？** 思路不变，过期条件从 `j <= i - k` 改成 `ts[j] <= ts[i] - T`。单调队列只依赖“先进先出 + 只关心最大值”。

> [!Q]
> **要的是滑动窗口的中位数或 P99 呢？** 单调队列只能维护最值。中位数用两个堆加懒删除，或者有序容器（平衡树）$O(\log k)$ 增删；P99 这种近似分位数在线上一般用 t-digest 或分桶直方图。
