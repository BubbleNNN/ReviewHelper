有 `n` 门课，编号 `0..n-1`。`prerequisites` 里每一项 `[a, b]` 表示**上 a 之前必须先上 b**（边 b → a）。返回任意一个合法的上课顺序；如果存在环、无法完成，返回 `[]`。

```python
find_order(n, prerequisites) -> list[int]
find_order(4, [[1, 0], [2, 0], [3, 1], [3, 2]])   # [0, 1, 2, 3] 或 [0, 2, 1, 3]
find_order(2, [[1, 0], [0, 1]])                   # []
```

- 合法答案可能有多个，测试只检查“是 0..n-1 的一个排列，且每条边的起点都排在终点前面”。
- 可能有重复的边，也可能有自环 `[a, a]`（自环意味着有环）。
- 用 Kahn 算法（BFS + 入度）实现。

场景：verl 的一个 PPO step 可以看成一张 DAG：`gen → reward / old_log_prob / ref / values → adv → update_critic / update_actor`。调度器要先算出一个拓扑序，再把没有依赖关系的节点并发执行。

### 讲解

**Kahn 算法**：

1. 建邻接表，统计每个点的入度；
2. 所有入度为 0 的点入队；
3. 出队一个点 u，加入答案；对 u 的每个后继 v 入度减 1，减到 0 就入队；
4. 结束时答案长度 < n，说明剩下的点都在环上（或依赖环上的点），返回 `[]`。

**复杂度**：$O(V + E)$。

**为什么能判环**：环上的点入度永远不会减到 0，永远进不了队列。

**易错点**：

- 边的方向：`[a, b]` 是 b → a，写反了会得到逆序。
- 重复边要么去重，要么入度和邻接表都按重复计数，**两边必须一致**。
- 用 DFS 也可以：后序遍历的逆序就是拓扑序，三色标记（白/灰/黑）遇到灰色点就说明有环。

> [!Q]
> **怎么把拓扑序变成并行调度？** 按“层”出队：每一轮把当前所有入度为 0 的点一起取出，这一层内部没有依赖，可以并发跑。层数就是关键路径长度（假设每个节点耗时相同）。节点耗时不同时，要按最长路径（critical path）做优先级。

> [!Q]
> **如果要求字典序最小的拓扑序呢？** 把普通队列换成最小堆，复杂度变成 $O((V+E)\log V)$。
