返回数组中第 `k` 大的元素（`k` 从 1 开始，按排序后的位置算，重复元素各算一次）。用两种方法实现：

```python
kth_largest_quickselect(nums, k) -> int   # 期望 O(n)
kth_largest_heap(nums, k) -> int          # O(n log k)
kth_largest_quickselect([3, 2, 1, 5, 6, 4], 2)          # 5
kth_largest_heap([3, 2, 3, 1, 2, 4, 5, 5, 6], 4)        # 4
```

- **不要修改输入列表**（需要的话先复制）。
- 测试里有一个 20000 个**相同元素**的数组，并限制了运行时间。普通的两路划分在这种输入上会退化成 $O(n^2)$。

场景：top-k 采样要找出 logits 里第 k 大的值当阈值，把小于它的都屏蔽掉。GPU 上不会整体排序，而是用 radix select 一类的选择算法。

### 讲解

**快速选择**：第 k 大等价于升序第 `n-k` 小（0-based 下标 `t = n - k`）。

1. 随机选 pivot，做**三路划分**：`< pivot`、`== pivot`、`> pivot`；
2. 如果 `t` 落在小于区，只在小于区继续；落在等于区，答案就是 pivot；否则在大于区继续，并把 `t` 减去前两区的长度。

用循环而不是递归写，不会爆栈。

| 方法 | 期望时间 | 最坏 | 额外空间 |
|---|---|---|---|
| 排序 | $O(n\log n)$ | $O(n\log n)$ | $O(n)$ |
| 大小为 k 的最小堆 | $O(n\log k)$ | 同左 | $O(k)$ |
| 快速选择（随机 pivot） | $O(n)$ | $O(n^2)$，概率极低 | $O(n)$（这里的写法）或原地 $O(1)$ |
| 中位数的中位数 | $O(n)$ | $O(n)$ | 常数大，面试说出名字即可 |

**为什么期望是 $O(n)$**：每轮期望丢掉一个常数比例的元素，$n + \frac{3}{4}n + (\frac{3}{4})^2 n + \cdots = O(n)$。

**易错点**：

- 两路划分（Lomuto / Hoare）遇到大量重复元素时，每次只能排除一个元素，退化成 $O(n^2)$。三路划分（荷兰国旗）一步就能把所有等于 pivot 的元素排除。
- 固定选第一个元素当 pivot，在已排序的输入上同样退化。
- 堆的方向：求第 k **大**，用大小为 k 的**最小**堆，堆顶就是答案。

> [!Q]
> **GPU 上的 top-k 怎么做？** 常见是 radix select：按浮点数的二进制位从高到低逐位统计直方图，每一轮确定第 k 大落在哪个桶，几轮之后就锁定阈值，全程并行、不需要比较排序。k 很小时也可以每个 block 维护局部 top-k 再归并。

> [!Q]
> **流式数据（数据一个一个来）求第 k 大？** 只能用大小为 k 的最小堆，每来一个数和堆顶比较，$O(\log k)$。
